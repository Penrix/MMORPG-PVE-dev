## 0. 一句话裁决

第三模块不是一个“精彩度评分器”，也不是在 Agent/World Simulation 之后挑最大的冲突。

正确分层：

```text
第一层｜Reality Runtime
────────────────
世界真实运行
人物独立行动
人与人碰撞
组织行动
世界事件发展

回答：
“这个世界里真实会发生什么？”


第二层｜Expectation / Narrative Runtime
────────────────
Reader 需求 / 主线情绪
稀缺性
固有认知
主角优势
信息差
代入感
三阵营
铺垫 / 加价 / 兑现 / 反应
Reader Time 分配

回答：
“这些真实可能性里，什么值得写？
现在应该铺垫、加价还是兑现？
Reader 的有限注意力应该投在哪里？”
```

**第一层负责不能假；第二层负责不能无聊。**

但第二层不得为了“好看”改写第一层已经成立的人物意志、世界规则或 Reality。

## 0.5 设计顺序与因果顺序：第二层先设计，但第一层拥有现实裁决权

这里必须区分两种“先后”。

### 设计顺序

按照讲师原稿与当前项目方法，**第二层先设计**。

不是先让整个世界无目标地模拟一遍，再从十件随机事件里找一件“最精彩”的。

作者侧应先确定：

```text
Reader 当前需求 / 主线情绪
        ↓
这一阶段要经营哪一笔期待
        ↓
什么目标需要被塑造成稀缺
        ↓
什么世界/圈层/人物固有认知需要建立或加深
        ↓
主角当前真实拥有的反常识优势是什么
        ↓
未来想看哪些人物的认知被打破、关系重新定价
        ↓
最好留下什么真实资产 / 身份 / 权限 / 关系 / 入口
```

这份设计决定第一层应该优先观察：

- 哪些人物；
- 哪些组织与圈层；
- 哪些资源、能力、制度与信息；
- 哪些现实压力；
- 哪些人物认知与利益下注。

因此：

> **第二层先决定“这阶段值得经营什么”，第一层才知道“世界运行时重点听哪些声部”。**

### 因果顺序

第二层先设计，而且可以明确设计商业男频需要的角色下注与Payoff方向。不能预写的是“已经发生的Canon事实”，不是不能设计剧情。

真正的权限分工是：

```text
Expectation Design
        ↓
Reality Runtime
        ↓
人物在作者已定人物线内，基于自身 Observation / Goal / 利益选择具体演法
        ↓
World Arbitration 检查硬事实可行性
        ↓
speculative result
        ↓
Expectation Runtime 再决定：
继续 seed / charge / payoff / reprice
```

第二层只能设计：

- 目标情绪；
- 稀缺性建设方向；
- 固有认知建设方向；
- 值得优先激活/观察的人和世界变量；
- 期待兑现方向；
- 预期值得收割的反应；
- 期望留下的 Reality Gain。

第二层可以设计：

- 哪些现成人物应该卷进这条故事线；
- 哪个人基于什么固有认知下注；
- 谁继续误判、谁加注、谁承担未来识货/后悔/投靠/破防等Payoff；
- 人物线怎样通过 Before / During / After 被铺垫和结算。

但具体动作、对白和演法必须符合人设、利益、已知信息与硬 Reality。

如果第一层真实运行得到的结果与原 Expectation Design 不同：

```text
不是强改人物
而是：
Expectation Design
        ↓
延期 / 转向 / 重定价 / 换兑现路径
```

因此第三模块真正的循环不是：

```text
第一层 → 第二层
```

而是：

```text
第二层先设计期待
        ↓
第一层真实运行
        ↓
第二层经营 Reader Time
        ↓
第一层继续运行
        ↓
第二层兑现或重定价
        ↓
循环
```

**第二层拥有叙事目标权，第一层拥有现实因果权。**

这两个权力必须分开。

## 1. 本轮认知来源与形成史

本轮第二层不是从通用“Director”概念重新发明，而是重新逐行读取用户提供的四份讲师原稿，并把其中已经讲清楚的“什么值得写”翻译成 Runtime 语义：

- `基础课.md`
- `第一课：大纲细纲构造.md`
- `第二课：期待感的构成.md`
- `第三课：情绪拉扯，细纲写法.md`

重点锚点来自第二课与第三课。

### 1.1 关键原话锚点

短句只作为语义锚，不替代原稿：

- “期待感是由配角认知和主角优势的差值产生的。”
- “反应：固有认知然后打破（稀缺性构造的）。”
- “我们所塑造的稀缺性，在配角眼中是不是他们的常识？”
- “主角一切的目标追求都可以增添稀缺性，他能加深配角的固有认知，从而让读者期待打破它。”
- “三阵营的落笔，不是从【震惊】开始的！而是从【铺垫】开始的！”
- “节奏是拉主线的频率”，本质落到情绪累计。

### 1.2 本轮纠正了此前两个过浅理解

**纠正 A：固有认知不是单个 NPC 的临时 belief。**

此前容易写成：

```text
NPC A believes X
```

现在确认更准确的是：

> 固有认知是当前故事中已经足够稳定、足够可信、足以支配人物判断与行动的默认认知。它通常以世界共识 / 圈层常识 / 身份刻板判断 / 历史经验为底，再落到具体人物身上。

**纠正 B：第二层不是给十个真实事件打“精彩度分”。**

一个事件即使没有高潮，只要它正在：

- 证明某件事稀缺；
- 固化一个未来可打破的认知；
- 让人物在该认知上继续下注；
- 扩大人物认知与主角真实优势的差；
- 加重 Reader 的主线欲望；
- 增强代入；
- 为未来三阵营反应准备筹码；

它就可能值得占 Reader Time。

反过来，大战、死人、会议、升级如果没有参与任何期待交易，也可能只应背景化或略过。

## 2. 三个核心概念的正式语义

### 2.1 稀缺性 Scarcity

**不是一个 rarity score。**

不是：

```text
SSR = 5
UR = 10
```

而是：

> 通过世界事实、取得门槛、成本、失败历史、社会价格、权威人物判断和相关人物经历，把某个目标/结果塑造成“正常条件下极难获得、极少发生、极难突破”的东西。

典型构成：

```text
世界规则
+ 门槛
+ 成本
+ 失败历史
+ 成功样本稀少
+ 权威/专业圈层判断
+ 社会价格
+ 有多少人的利益押在这件事上
= 稀缺性证据
```

稀缺性的直接作用不是“物品更贵”，而是：

```text
稀缺证据
    ↓
形成 / 加深固有认知
    ↓
提高未来“打破认知”的价格
    ↓
提高人物反应的价格
```

因此：

- 元婴高不是爽点；“无数人做不到”成为世界常识后，主角做到才贵。
- 治病不是爽点；整个专业圈层和利益相关者都已按“治不好”行动后，主角治好才贵。
- 同一件物品在现代和匮乏年代，Narrative Price 可以完全不同。

### 2.2 固有认知 Established Belief / Consensus

**不是一个随手生成的 NPC 看法。**

正式定义：

> 被当前相关人物稳定相信，并已经足以支配其判断、选择、投资与行动的默认认知。

它至少有四个尺度：

| 层次             | 例子                     |
| ---------------- | ------------------------ |
| 世界常识         | 这个境界正常极难突破     |
| 圈层 / 行业共识  | 太医院认定此病无解       |
| 身份默认认知     | 一个镀金官二代不懂科研   |
| 具体人物固化判断 | 前女友认定男主一辈子没钱 |

第三模块不能凭空写：

```text
“大家都觉得 X”
```

它必须尽量能回溯到第二模块和当前 Reality 的证据：

```text
Power / Rule
Resource / Cost
Institution / Access
History / Failure
People / Authority
Organization / Practice
Value / Social Price
Information / Knowledge
        ↓
World / Circle Consensus
        ↓
具体人物结合自身经历与利益
        ↓
Character Established Belief
```

### 2.3 期待感 Expectation

讲师最基础公式：

```text
Expectation
=
配角认知
↔
主角优势
之间的差值
```

但 Runtime 不能只存一个 gap 数字。完整期待状态至少要求：

```text
固有认知
+
主角真实优势
+
Reader 已经知道/部分知道该优势
+
相关人物仍然按照旧认知行动
+
未来存在一个认知抚平/打破节点
```

如果 Reader 也不知道主角优势，那可能是悬念，不是本轮定义的认知差期待。

如果配角嘴上说错，但没有据此做任何选择，认知价格也很低。

## 3. “人物下注”是期待加价的核心

同一句：

```text
“主角不可能成功”
```

价格可以完全不同。

低价：

```text
路人随口说一句
```

高价：

```text
反派相信主角不可能成功
    ↓
抢主角产业
    ↓
押全部资源到另一人身上
    ↓
公开承诺
    ↓
按“主角永远翻不了身”制定未来计划
```

友方也一样：

```text
妹妹知道练武真的很难
但决定相信哥哥
    ↓
去打工
    ↓
投入自己的钱和生活
```

以后主角成功，兑现的不只是“震惊”，还有：

- 奉献被兑现；
- 报恩；
- 欣慰；
- 关系升值；
- 身份变化；
- 权限和资源变化。

因此，**三阵营的本质不是三个标签，而是不同立场/利益的人如何在同一个固有认知上下注。**

---

## 4. 三阵营必须从铺垫开始，不从“震惊”开始

错误实现：

```text
主角成功
→ Director 临时生成：
  友方震惊
  敌方震惊
  中立震惊
```

这是廉价反应。

正确实现：

```text
成功之前

友方：
相信什么？
担心什么？
投入了什么？
为主角承担过什么？

敌方：
相信什么？
说过什么？
做过什么？
压了什么利益和计划？

中立：
基于行业常识如何判断？
有没有实际资源/身份/评价下注？

        ↓

主角 Reality 改变

        ↓

这些真实判断被撞坏

        ↓

Agent / 人物重新反应

        ↓

三方反应具有真实价格
```

这也是 Character Agent 与商业男频 Narrative Runtime 真正接上的地方：

> Agent 越真实地按自己的有限认知行动，就越可能自然给未来认知打破加仓，而不是为了爽点故意降智。

---

## 5. 反应是 Reader 情绪兑现，Reality Gain 是人生资产兑现

讲师原稿强调：单纯“获得一亿、升级一个境界、成为皇帝”不等于 Reader 已经感受到爽；真正的情绪价值需要通过人物和世界的反应体现。

这与项目既有“赢麻了”宪法结合后，必须同时做两种 Settlement：

```text
Reality Settlement
男主真实赢到什么？
资产 / 身份 / 权限 / 关系 / 能力 / 地盘
        +
Reader Settlement
这些真实获得在人和世界身上产生什么可感知反应？
```

只写反应，没有真实资产，是空爽。

只写资产数字，没有人物/世界反应，Reader 可能感受不到价格。

完整赢：

```text
真实权益上涨
+
人物/世界重新定价男主
+
新的更贵期待打开
```

## 6. 代入感决定“知道”什么时候必须变成“感受到”

第三课的核心不是要求每个状态都展开五感，而是：

> 情绪只有落进具体的现实、人物关系、衣食住行、尊严、场景与行为中，Reader 才可能从“知道这个信息”变成“感受到这个处境”。

因此 Narrative Runtime 需要区分：

```text
Reader knows
≠
Reader feels
```

如果一个重要主线压力 Reader 只有摘要式知识：

```text
“主角很穷”
“练武很难”
“这个身份没地位”
```

则 Narrative Runtime 可以判断：

- 还不能兑现；
- 需要继续分配场景；
- 用真实生活 / 人际 / 制度 / 资源细节把该情绪具体化。

Reader Time 因而不是“事件越大占得越多”，而是：

> 当前主线情绪和期待交易还需要多少真实演出才能成立。

---

## 7. 节奏是期待与情绪的运行曲线，不是固定高潮间隔

禁止把节奏写成：

```text
三章一个爽点
五章一个高潮
```

当前语义：

```text
节奏
=
主线情绪被拉动的频率
+
期待势能的建立 / 加价 / 部分兑现 / 再定价
```

每一轮 Narrative Runtime 都应关心：

- 当前主线情绪最近是否仍在被拉动？
- Reader 对当前目标的欲望是在涨、持平还是被遗忘？
- 稀缺性是否真正被世界/人物演出来？
- 固有认知是否越来越牢？
- 认知差是否扩大？
- 是否已经到应兑现时机？
- 是否只兑现一部分，以开启更高价格？
- 兑现后有没有新权益与新期待？

## 8. 第二层真正的 Reader Time 分配规则

第一层可能同时产生：

```text
医院医生换班
根部调查伤员
朔茂执行任务
商店进货
火影开会
伤员死亡
忍者谈恋爱
秀信测试忍术
某家族内部争吵
边境传回战报
```

第二层不问“哪件最大”，而问每个候选是否正在：

1. **Seed**：种下一个未来有价值的需求 / 期待；
2. **Scarcity**：证明目标为什么难、贵、少见；
3. **Consensus**：建立或固化世界 / 圈层 / 人物默认认知；
4. **Gap**：扩大人物认知与主角真实优势的差；
5. **Pressure**：加重当前主线情绪与人物关系压力；
6. **Embodiment**：把 Reader 从“知道”推进到“感受到”；
7. **Stake**：让友 / 敌 / 中立在认知上实际下注；
8. **Payoff**：打破认知、抚平信息差；
9. **Reaction**：兑现已经铺垫过的人物反应；
10. **Retained Gain**：让男主留下真实资产 / 身份 / 权限 / 关系；
11. **Reprice**：兑现后打开更贵的下一层认知与期待。

因此一个“医生换班”如果只是日常：

```text
background / skip
```

但如果换班会让唯一知道秀信异常的医生把记录交给受根部控制的人，它同时承担：

```text
Information propagation
+ Consensus shift
+ New observer
+ Future expectation charging
```

就可能非常值得写。

## 9. Expectation Runtime 的持久对象

第二层不要做一个 `scarcityScore / expectationScore` 表。

第一批 Contract 应优先表达关系与证据：

### ScarcityEvidence

“为什么这件事难/贵/少见”的证据。

### EstablishedBelief

世界 / 圈层 / 身份群体 / 具体人物的默认判断，以及该判断已经驱动了哪些行动和下注。

### ProtagonistAdvantage

主角真实拥有的反常识优势；Reader 是否知道；哪些人物知道。

### ExpectationThread

一笔正在运行的期待交易：

- Reader 想要什么情绪；
- 期待什么结果；
- 当前稀缺证据；
- 当前固有认知；
- 当前主角优势；
- Reader 知道多少；
- 哪些人物已下注；
- 兑现条件；
- 预期要看的反应；
- 当前处于 seeding / charging / ripe / payoff / settled 哪个状态。

### NarrativeCandidate

来自第一层 Reality Runtime 的真实/模拟候选，不是第二层自由编出来的剧情。

### NarrativeAllocation

对候选分配：

- skip / background / seed / charge / payoff
- none / brief / scene / chapter Reader Time
- 它正在给哪条 ExpectationThread 加什么价
- 为什么值得写
- 为什么此刻还不能兑现
- 如果兑现，必须回收哪些已铺垫反应

## 10. 开放状态机

Expectation Thread 不是固定流水线，允许分叉、回返、延期：

```text
                ┌───────────────┐
                │    seeding    │
                └───────┬───────┘
                        ▼
                ┌───────────────┐
        ┌──────►│   charging    │◄──────┐
        │       └───────┬───────┘       │
        │               │               │
  新稀缺证据        认知差成熟      Reality 改变
        │               ▼               │
        │       ┌───────────────┐       │
        └───────│     ripe      │───────┘
                └───────┬───────┘
                        │
              可以继续加价 / 可兑现
                 ┌──────┴──────┐
                 ▼             ▼
             charging        payoff
                               │
                               ▼
                           reaction
                               │
                     ┌─────────┴─────────┐
                     ▼                   ▼
                  settled            reprice
                                         │
                                         ▼
                                  新 ExpectationThread
```

**“已经 ripe”不等于必须马上兑现。**
如果真实人物行动继续自然加价，而且没有拖垮 Reader 欲望，可以继续 charging。

## 11. 原创与同人统一

武道文只是讲师的演示载体。

原创：

```text
世界共识：
寒门极难成为大修士

主角优势：
特殊功法 / 金手指
```

同人：

```text
原著共识：
基础忍术上限有限
某血继只能由某族使用
某人物不可能认可某类人
某历史事件“正常会这样发生”

主角优势：
未来记忆
身份反差
对基础能力的不同理解
已经建立但别人未知的关系
```

同人甚至天然拥有大量现成高价固有认知：

- 原著 Reader 已经熟悉的人物；
- 原著社会层级与规则；
- 原著能力价格；
- 原著人物正常反应模式；
- 原著历史“应该怎样发生”。

因此同人第二层不是换逻辑，而是：

> 找到主角能在哪个已成熟的原著固有认知上制造可信差值。

## 13. 硬禁令

后续实现不得：

- 把稀缺性压成一个数字评分。
- 把固有认知压成“NPC A believes X”而丢掉世界/圈层共识来源。
- 在主角成功后临时生成一群“震惊”角色，冒充铺垫后的反应。
- 用仇恨/嘲讽替代稀缺性与固有认知建设。
- 把“事件大”当成“值得写”。
- 把 Reader Time 当固定章节节拍。
- 为了制造期待，让人物知道他不该知道的信息。
- 为了爽点，强迫 Agent 违背自己的 Observation / Goal / 利益。
- 把第二层输出自动写入 Canon。
- 只结算人物反应，不留下真实权益。
- 只结算真实权益，不让 Reader 感受到其价格。
