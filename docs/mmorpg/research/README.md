## 工程使用纪律

- 原稿全文**单独保存，不改写，不丢具体案例**。运行时避免把七部完整手册一次性塞入模型，而是由 `packages/narrative/src/mmorpg-method-catalog.ts` 通过范围、题材、当前对象选择**真正原文节选**。
- 这些节选在 `packages/narrative/src/world-pack-workers.ts` 中通过**实际移植的 Covel `orderSources`**按依赖拼装：研究方法 → 导入的已有 Covel 世界包 → 已确认 Canon Reality → 作者当前指定对象。
- 选择资料入口 ≠ 实现原始状态机。v0.2 的对象探索/分叉/回返、v0.3能力规则、v0.5资源转玩法、v0.6传播、v0.7 GM/GOAP依旧需要代码层继续开发。不能把此索引或提示词叫“全量实现”。
- 仅在故事人物进入当前世界之后才做男主个人Build；World Builder默认先产生独立的世界生态。不为金手指新增代价，不让空洞合理化取代昂贵的男频世界资产。
