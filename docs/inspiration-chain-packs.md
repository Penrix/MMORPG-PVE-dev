# 灵感链卡池（inspiration chain packs）

一句话灵感不是四个词，是一条**取得链**。四槽随机拼装会把 A 的身份接上 B 的结局，
所以本地发牌的单位是「整条链」，链内不拆。

## 一条链的五段

| 段         | 回答的问题                       | 落到槽位                                |
| ---------- | -------------------------------- | --------------------------------------- |
| identity   | 他在哪、是什么身份               | identity                                |
| leverage   | 他凭什么能动手                   | anomalyRule                             |
| gatekeeper | 他要的东西在谁手里、隔着哪道门   | highValueCircle                         |
| firstTake  | 他第一次实际拿走了什么           | starterBlueprint.firstTake（大纲 goal） |
| inbound    | 谁因此找上门，带着什么更贵的东西 | twistPressure（大纲 conflict）          |

**第四段必须是已经拿到手的资产**，不是「他很强」。
**第五段必须带标的**：对手上门要带着主角想要的东西，否则就是给他添麻烦，大纲会写成受苦。

## 包（pack）

一个包 = 一个地方或一个组织。包内所有链共享同一套世界语义，所以任意一条都能单独发，
不需要和别的链拼接。当前内置：

- 男频：边镇军帐 / 仙门药谷 / 港城黑市 / 夜拍场
- 女频：豪门婚宴 / 深宅宫闱 / 名利场 / 新赛道
- 混合：午夜街铺 / 异界入口 / 老物件 / 雨夜救援

## 发牌规则

- 本地模式按链发牌，**不跨链、不跨包**。
- 请求数超过库存时按库存返回：一条重复的故事比一批短卡更糟。
- 锁槽 = 只保留包含这句话的那条链，不再重摇其余三槽。
- 项目素材（M03）只计入池子统计，不掺进内置包；要掺就整包换成项目自己的世界包。

## 加一个新包

1. 先定一个具体地方，不写「修真界」这种大词。
2. 写 3–6 条链，全部落在同一个地方。
3. 每条链的 firstTake 写成「我 + 动作 + 拿到的东西」。
4. 每条链的 inbound 写成「谁 + 带着什么来」。
5. 自检：任意抽一条单独念出来，读者能不能立刻看见他在哪、拿走了什么、谁不服。

## LLM 路径

LLM 仍按四槽模具生成，但提示词已加一条硬约束：四槽必须同属一个世界、同一条因果链；
模具跨世界时以 identityHint 为准重写其余三槽，不得硬拼。
