# 模块二 · 源世界母体库（World Atlas）持续填充队列

基于 `datasets/newbook-rankings/newbooks.jsonl`（272 本真实新书：番茄 190 + 起点 73 + 刺猬猫 9）的题材统计，结合用户指定的常见同人与历史/年代母体世界，按**高频刚需 + 每批 12~15 张小粒度微批次**推进，防止网页模型卡死或跑偏。

---

## 生产铁律（每次给 ChatGPT Web 派单必守）

1. **一世界一对话**：不同世界绝不混在同一个 ChatGPT 网页会话里，防止设定串味。
2. **微批次投喂**：每次只让 ChatGPT Web 产出 **12~15 张卡**（单次控制在 4,000~6,000 字），绝不一次发整套世界清单。
3. **强制去百科废话**：每张卡必须写清「社会价格 / 准入门槛 / 资源或权力流向 / 人物欲望与筹码 / 制度暗面或冲突引线」，末尾带 3~6 条 `关系名：[[目标]]` 语义链接。
4. **增量实时入库**：每回收一批 → 校验 JSON → 存入 `datasets/world-atlas/<worldId>/batch-XX.json` → 立刻跑 `npx tsx scripts/import-world-atlas.ts --dir datasets/world-atlas/<worldId>` 写入本地 SQLite，并把脚本报出的高频未落地 `[[目标]]` 直接喂给下一批。
